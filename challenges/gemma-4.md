# Best Use of Gemma 4

**Official MLH challenge • 2-hour Hack Day build**  
Hacktoberfest Hack Day • Hyderabad | MLH × DEV × React Hyderabad

Build a focused experience that turns information in images, screenshots, documents, diagrams, or other inputs into a useful result with Gemma 4.

## Requirements from the final brief

- Meaningfully use **Gemma 4 through the Gemini API**.
- Use multimodal capability where it adds value; text and image are a natural fit, but other supported directions are welcome.
- Give the experience one clear user story and a working end-to-end prototype.
- Make the Gemma-powered result obvious within the first 30 seconds of the demo.

The API access requirement comes from the supplied challenge brief. Confirm available model access with the organizers before building; a different model or access route should not be assumed to satisfy the requirement.

## Idea directions

Explain a screenshot error, extract fields or actions from a document, summarize a diagram, or help someone learn from a visual input. Examples are inspiration; choose a focused problem that you can demonstrate reliably.

## Suggested 120-minute build plan

| Minutes | Milestone |
| --- | --- |
| 0–15 | Define one user, one problem, and one useful moment |
| 15–35 | Wire the UI, Gemini API call, and sample input |
| 35–80 | Complete the input → Gemma → result workflow |
| 80–105 | Refine prompts, validation, error states, and polish |
| 105–120 | Prepare a seeded example, backup input, and demo story |

## Demo and submission evidence

Show the input and then the Gemma result. Explain the problem in one sentence and show where multimodal understanding adds value. Identify the model and API integration in your code. Keep the demo under two minutes, test it twice, and have a fallback sample or screenshot if the API call fails.
