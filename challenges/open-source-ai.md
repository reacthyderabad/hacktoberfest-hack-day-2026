# Best Open-Source AI Project

**Official MLH challenge • 2-hour Hack Day build**  
Hacktoberfest Hack Day • Hyderabad | MLH × DEV × React Hyderabad

Build an original, useful project where open-source or open-weight AI is an important part of the product.

## Requirements from the final brief

- Make the AI component central to the workflow, rather than a decorative add-on.
- Publish the project in a public GitHub repository with an open-source license.
- You may build an application with an open-weight model, an agent skill, or a model harness.
- Agent skills must comply with the Agent Skill Open Standard.
- A harness submission must include an original implementation or meaningful changes to an existing open-source harness.

Using an AI coding assistant to write code alone does not satisfy this challenge. Show the AI component in the architecture and in the demo.

## Idea directions

Explain an unfamiliar repository, help contributors navigate an open-source project, diagnose a bug, build a reusable agent skill, or create a model-powered tool for a specific user workflow. Other ideas are welcome when they meet the requirements.

## Suggested 120-minute build plan

| Minutes | Milestone |
| --- | --- |
| 0–15 | Choose a model, skill, or harness and one user story |
| 15–30 | Bootstrap the repository, license, model/tool, and sample input |
| 30–80 | Build one working end-to-end workflow |
| 80–105 | Improve validation, prompts, UI, and errors |
| 105–120 | Finish the README and prepare a two-minute demo |

## Demo and submission evidence

Show the public repository and license. Identify the AI component and explain why it matters. Run the core workflow live. For a skill, demonstrate invocation and the result; for a harness, explain the original implementation or meaningful modification.
