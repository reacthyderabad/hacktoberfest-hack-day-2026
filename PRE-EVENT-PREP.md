# Pre-Event Prep — Hacktoberfest Hack Day

This is the quick checklist to go through before coming to the event.

You do **not** need to be an AI/ML expert. The goal is simply to revise the basics, understand the challenge categories, and make sure your laptop is ready so you can spend more time building during the Hack Day.

---

## 1. Revise Git & GitHub Basics

Be comfortable with:

```bash
git clone
git add
git commit
git push
git pull
```

Also revise:

- Creating a GitHub repository
- Branches and commits
- Public repositories
- Forking a public repo.
- Writing a basic `README.md`
- Adding an open-source license

Your final project must be published in a **public GitHub repository** with an **open-source license**.

Reference:
- GitHub Licensing: https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository
- Choose a License: https://choosealicense.com/

---

## 2. Revise One Programming Language

You should be comfortable with at least one:

- JavaScript / TypeScript
- Python

Use the language and stack you are already comfortable with.

You do **not** need to learn a new programming language just for the Hack Day.

---

## 3. Revise Basic API Concepts

Make sure you understand:

- What an API is
- GET and POST requests
- Sending and receiving JSON
- Calling an external API from your application
- Basic frontend-to-backend communication

---

## 4. Revise Basic AI Concepts

Have a basic understanding of:

- LLMs
- Prompts
- Context
- Tokens
- Open-source vs open-weight AI
- AI agents
- Tool calling

Good to know if you have extra time:

- RAG
- Embeddings
- Agent Skills
- Model harnesses

You only need a high-level understanding before the event.

# Partner Technologies & Challenge Categories

The three planned event challenges are listed in [PROBLEM_STATEMENTS.md](PROBLEM_STATEMENTS.md). The technologies below are learning resources, not a list of additional event categories. Choose the tools relevant to your project.

For the local Build on elah challenge, review the [elah brief](challenges/elah.md) and prepare a Chromium browser and Node.js environment.

## Google Gemma

Gemma is Google's family of lightweight, open-weight models.

For the MLH challenge, participants can build with **Gemma 4 through the Gemini API**.

Revise:

- What an open-weight model is
- Basic prompt and API usage
- How an AI model can be integrated into an application

References:
- MLH Gemma Challenge: https://hacktoberfest-handbook.mlh.com/hack-days-partner-modules/partner-challenge-google-gemma
- Gemma Resources: https://mlh.link/gemma
- Gemma Quickstart: https://mlh.link/gemma-quickstart
- Gemma API Docs: https://mlh.link/gemma-docs
- Gemma Beginner Guide: https://mlh.link/gemma-beginnerguide

## Snowflake CoCo

Snowflake CoCo is an AI coding agent for data work.

For the MLH challenge, the project should combine:

1. Snowflake CoCo
2. A freely accessible Snowflake dataset
3. Open-source or open-weight AI

Revise:

- Basic SQL and datasets
- How data can be used inside an AI application
- Basic idea of data pipelines

References:
- MLH Snowflake Challenge: https://hacktoberfest-handbook.mlh.com/hack-days-partner-modules/partner-challenge-snowflake-coco
- Snowflake CoCo Overview: https://docs.snowflake.com/en/user-guide/cortex-code/cortex-code
- Snowflake Sample Data: https://docs.snowflake.com/en/user-guide/sample-data
- Snowflake Marketplace: https://docs.snowflake.com/en/collaboration/consumer-listings-exploring

## Solana Agent Registry

The Solana Agent Registry is an open, onchain protocol for giving AI agents verifiable identities, reputation, feedback, and validation records.

Revise:

- What an AI agent is
- Very basic blockchain/onchain concepts
- Why an AI agent may need identity, reputation, or validation

References:
- MLH Solana Challenge: https://hacktoberfest-handbook.mlh.com/hack-days-partner-modules/partner-challenge-solana
- Solana Agent Registry: https://solana.com/agent-registry
- Solana Hack Day Resources: https://mlh.link/solana
- Solana Documentation: https://mlh.link/solana-docs
- Solana Tutorials: https://mlh.link/solana-tutorials

---

## GitHub Copilot

GitHub Copilot can be used as an AI pair programmer while planning, coding, testing, debugging, and documenting your project.

For the MLH challenge, teams should be able to explain how Copilot helped them build the project.

Revise:

- Basic Copilot usage
- Prompting Copilot clearly
- Using Copilot for code, tests, debugging, and documentation

References:
- MLH GitHub Copilot Challenge: https://hacktoberfest-handbook.mlh.com/hack-days-partner-modules/partner-challenge-github-copilot
- GitHub Student Access: https://mlh.link/GitHub

# What to Have Ready Before Coming

Please have:

- [ ] Laptop
- [ ] Laptop charger
- [ ] Git installed
- [ ] GitHub account ready
- [ ] Code editor installed
- [ ] Node.js or Python installed
- [ ] Working browser
- [ ] Basic Git/GitHub knowledge revised
- [ ] Basic API concepts revised
- [ ] Basic LLM concepts revised
- [ ] Basic understanding of open-source licensing
- [ ] Basic understanding of the four MLH partner challenge categories

### Check your setup

For JavaScript / TypeScript:

```bash
node --version
npm --version
git --version
```

For Python:

```bash
python --version
pip --version
git --version
```

If these commands work, your basic development setup is ready.

# Important

Do **not** build your Hack Day submission before the event.

Before coming, focus on:

- Revising the basics
- Preparing your development environment
- Understanding the challenge categories
- Reading the relevant documentation
- Exploring small examples if you want

The actual project should be built during the Hack Day according to the event rules.
