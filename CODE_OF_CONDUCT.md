# Code of Conduct

We want a welcoming community for participants, mentors, organizers, and reviewers. Be respectful of different backgrounds and experience levels, offer constructive feedback, and credit others' work.

Harassment, discrimination, threats, unwanted sexual attention, doxxing, and dishonest attribution are unacceptable. Respect people's privacy and requests to stop unwanted interactions.

The [MLH Code of Conduct](https://static.mlh.io/docs/mlh-code-of-conduct.pdf) applies to participation in the MLH event. Follow the organizers' event policies as well.

Report event concerns privately to the on-site organizers or through the reporting channels in the MLH Code of Conduct. Do not publish private incident details in GitHub issues. Repository maintainers may remove harmful content or restrict participation in repository discussions.
